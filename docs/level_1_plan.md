# План первого уровня

## Цель первого уровня

Первый уровень нужен, чтобы проверить самый простой цикл игры:

`Level2D → Enemy2D → DuelArena3D → Win → Level2D → Enemy исчез`.

Игрок должен увидеть временный 2D-уровень, дойти до врага, перейти в дуэль, победить и вернуться обратно.

## Состав уровня

В уровне есть только временные объекты:

- игрок;
- земля;
- один враг `enemy_01`;
- ящик;
- выход;
- камера.

Все объекты сделаны простыми формами. Финального визуала пока нет.

## Главный цикл

1. Запускается `Level2D`.
2. Игрок двигается и прыгает.
3. Игрок касается `Enemy2D`.
4. `GameManager` сохраняет позицию игрока и открывает `DuelArena3D`.
5. В дуэли игрок использует `Attack` и `Guard`.
6. Если HP врага становится 0, вызывается победа.
7. `GameManager` возвращает игрока в `Level2D`.
8. Побеждённый враг исчезает.

## Что нужно проверить руками

- Игра стартует с `Level2D.tscn`.
- Игрок виден.
- Земля видна.
- Враг виден.
- Ящик и выход видны.
- Игрок двигается влево и вправо.
- Игрок прыгает.
- Касание врага открывает `DuelArena3D.tscn`.
- В дуэли видны `AttackButton`, `GuardButton`, HP и состояние врага.
- `Attack` наносит урон только при состоянии `Open`.
- Ошибочная атака уменьшает HP игрока.
- Победа возвращает в `Level2D`.
- Побеждённый враг исчезает.

## Что будет на этапе 2

На этапе 2 можно будет улучшить прототип, но без перегруза:

- уточнить размеры и расположение уровня;
- добавить простые подсказки для игрока;
- улучшить временные визуальные формы;
- сделать поведение выхода полезным для перехода дальше;
- подготовить основу для следующего врага или следующей комнаты.
