# Ghost Katana: Duel Shift

Это ранний прототип проекта **Ghost Katana: Duel Shift** для Godot/Xogot.

Версия 0.1 нужна только для проверки базового цикла игры. Это не финальный вид игры.

## Что сейчас реализовано

- Проект открывается как Godot/Xogot-проект.
- Главная сцена: `res://scenes/Level2D.tscn`.
- `GameManager` подключён как Autoload.
- В 2D-сцене есть:
  - игрок;
  - земля;
  - враг;
  - временный ящик;
  - временный выход.
- Игрок может двигаться влево и вправо.
- Игрок может прыгать.
- При касании врага открывается 3D-арена дуэли.
- В дуэли есть кнопки `Attack` и `Guard`.
- В дуэли видны HP игрока, HP врага и состояние врага.
- Победа в дуэли возвращает игрока в 2D-сцену.
- Побеждённый враг исчезает из 2D-сцены.

## Как открыть в Xogot/Godot

1. Открой Xogot или Godot.
2. Выбери импорт проекта.
3. Укажи папку с этим репозиторием.
4. Открой проект.
5. Запусти проект кнопкой Play.

Проект должен стартовать со сцены `Level2D.tscn`.

## Что проверить после запуска

1. Нажать Play.
2. Убедиться, что открылась 2D-сцена.
3. Убедиться, что видны игрок, земля, враг, ящик и выход.
4. Проверить движение игрока влево и вправо.
5. Проверить прыжок игрока.
6. Коснуться врага.
7. Убедиться, что открылась 3D-арена.
8. Проверить, что видны кнопки `Attack` и `Guard`.
9. Проверить, что видны HP игрока, HP врага и состояние врага.
10. Атаковать, когда состояние врага `Open`.
11. Победить врага.
12. Убедиться, что игрок вернулся в 2D-сцену.
13. Убедиться, что побеждённый враг исчез.


## Если Xogot показывает ошибку скриптов

В этой версии скрипты написаны простым GDScript без строгих типов. Это сделано специально, чтобы Xogot на iPad легче открыл проект и не падал на ошибке `Parser Error: Failed to compile depended scripts`.

Если загрузка напрямую по ссылке GitHub не работает, можно скачать проект как ZIP с GitHub, распаковать его в Files на iPad и открыть папку проекта в Xogot.
